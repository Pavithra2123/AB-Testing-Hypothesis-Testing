# A/B Testing & Hypothesis Testing

## Project Overview
This project performs A/B Testing and Hypothesis Testing using Python to compare the performance of two groups (A and B).

## Objective
To identify which group has a better conversion rate using statistical analysis.

## Dataset
The dataset contains:
- UserID
- Group
- Visitors
- Conversions

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- SciPy
- GitHub

## Analysis Performed
1. Data loading and analysis
2. Conversion rate calculation
3. Comparison between Group A and Group B
4. Hypothesis testing
5. P-value calculation
6. Data visualization

## Hypothesis
- Null Hypothesis (H0): There is no significant difference between Group A and Group B.
- Alternative Hypothesis (H1): There is a significant difference between Group A and Group B.

## Conclusion
The project uses statistical hypothesis testing to determine whether the difference in conversion rates between the two groups is statistically significant.
